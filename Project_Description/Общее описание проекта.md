# Общее описание проекта

CalendarProject — учебный веб-сервис для управления задачами и проектами (HSSE 25-26).

## Что умеет сервис

- **Регистрация и авторизация пользователей с подтверждением email** — FastAPI, bcrypt (passlib), cookie-сессии (Starlette SessionMiddleware), itsdangerous
- **Создание проектов и вложенных задач любой глубины** — FastAPI, SQLAlchemy 2.0 (async), asyncpg, PostgreSQL
- **Ролевая система прав (Тимлид / Менеджер / Разработчик) с наследованием по иерархии** — SQLAlchemy ORM (модели TaskUserRole, TaskRolePermission), PostgreSQL
- **Назначение исполнителей на задачи** — SQLAlchemy ORM, FastAPI
- **Диаграмма Ганта для визуализации сроков** — Jinja2, ванильный JS, CSS
- **REST API для программного доступа ко всем функциям** — FastAPI, Pydantic v2, JWT (HS256)

## Стек

| Часть проекта | Технологии |
|---|---|
| Веб-фреймворк | FastAPI, Uvicorn (ASGI) |
| База данных | PostgreSQL |
| ORM и драйвер | SQLAlchemy 2.0 (async), asyncpg |
| Миграции схемы | Alembic |
| Авторизация (HTML) | Cookie-сессии (Starlette SessionMiddleware) |
| Авторизация (API) | JWT (HS256, 7 дней), OAuth2 password flow |
| Хеширование паролей | bcrypt (passlib) |
| Email-токены | itsdangerous (URLSafeTimedSerializer) |
| Шаблоны | Jinja2 |
| Стили | CSS (без фреймворков) |
| JavaScript | Ванильный JS, встроенный в шаблоны |
| Валидация данных | Pydantic v2 |
| Тесты | pytest, реальная тестовая БД |

## Структура приложения

```
app/          — бэкенд (FastAPI, ORM, CRUD, авторизация)
templates/    — HTML-шаблоны (Jinja2)
static/       — CSS, аватарки
alembic/      — миграции БД
tests/        — автотесты
```

## Ключевые архитектурные решения

- «Проект» и «задача» — одна таблица `tasks`; корневая задача (`parent_task_id IS NULL`) — проект, остальные — подзадачи.
- Права проверяются через `has_permission()`, которая идёт вверх по дереву задач до корня.
- HTML-роуты и API-роуты (`/api/v1/*`) работают параллельно: первые возвращают шаблоны и редиректы, вторые — JSON.
- Схема БД управляется только через Alembic; прямой `create_all()` не используется.
