# Этап 1: Подготовка окружения и архитектуры проекта

## Зачем нужен этот этап?
Для перехода с Flask на FastAPI нам нужны другие инструменты. FastAPI работает асинхронно, поэтому ему нужен специальный сервер (ASGI), а не тот, что используется во Flask (WSGI). Также, чтобы проект не превратился в «кашу», мы сразу разобьем его на логические модули вместо хранения всего в `server.py`.

## Что нужно изучить (Технологии):
1. **ASGI vs WSGI:** Понять разницу между синхронными веб-серверами (Flask/WSGI) и асинхронными (FastAPI/ASGI).
2. **Uvicorn:** Асинхронный сервер, который будет запускать наше FastAPI приложение.
3. **Модульная структура Python-проектов:** Зачем разбивать проект на папки `routers`, `models`, `schemas`.

## Подэтапы (Как будем реализовывать):
1. **Установка зависимостей:**
   В терминале будет выполнена команда:
   `pip install fastapi uvicorn asyncpg sqlalchemy pydantic python-jose passlib python-multipart`
   * `fastapi` — сам фреймворк.
   * `uvicorn` — сервер для запуска.
   * Остальные библиотеки нужны для базы данных, валидации и авторизации.
2. **Создание файловой структуры:**
   Мы создадим следующие папки и пустые файлы:
   * `app/main.py` (точка входа, замена server.py)
   * `app/database.py` (подключение к БД)
   * `app/models.py` (таблицы БД)
   * `app/schemas.py` (Pydantic-модели для JSON)
   * `app/routers/` (эндпоинты API)
3. **Написание базового main.py:**
   Напишем минимальный код для старта сервера: `app = FastAPI()` и тестовый роут `/ping`.
