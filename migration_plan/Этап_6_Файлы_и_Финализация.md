# Этап 6: Загрузка файлов и очистка

## Зачем нужен этот этап?
Нужно перенести функционал загрузки аватарок, который у вас был реализован через стандартный `request` Flask. В FastAPI для этого есть класс `UploadFile`. После этого мы сможем удалить все хвосты Flask, так как проект будет полностью перенесен.

## Что нужно изучить (Технологии):
1. **Загрузка файлов в FastAPI:** Классы `File` и `UploadFile` (и зачем нужна библиотека `python-multipart`).
2. **StaticFiles:** Как отдавать картинки по URL напрямую из папки.

## Подэтапы (Как будем реализовывать):
1. **Эндпоинт загрузки аватарки:**
   В `routers/users.py` добавим эндпоинт для приема картинки профиля. Заменим логику сохранения на асинхронную (`await file.read()`).
2. **Настройка статики:**
   В `main.py` добавим `app.mount("/static", StaticFiles(directory="static"))`, чтобы загруженные картинки можно было открывать по прямой ссылке.
3. **Очистка старого кода:**
   Удалим старый `server.py`, `db_requests.py`, и папку `templates/` (по желанию, вы можете сохранить их в другой ветке Git).
4. **Финальное тестирование:**
   Запустим сервер и проверим все через автоматическую документацию по адресу `http://localhost:8000/docs`.
